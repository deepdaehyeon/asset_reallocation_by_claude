> **요약**: ① 8/28 `^VIX9D` 1일치 부분 응답이 HMM 학습표를 1일로 붕괴시켜 Goldilocks 100% 위험증가와 다음날 역회전을 만든 문제, 그리고 9/1 국내 매도 한 건이 19분 동안 전체 주문을 막은 문제를 수정했다. ② 선택 피처 coverage gate·직전 정상 목표 동결·Crisis 위험축소 예외를 추가하고, 주문 timeout을 180초로 제한하면서 취소 확인 후 잔량만 재주문·부분체결 잔고 재확인·실패매도 영속 재트리거·잔고 API 캐시를 구현했으며 모의 회귀 테스트 6건과 기존 46건이 모두 통과했다. ③ 채택 — 데이터 장애가 신규 risk-on 목표를 만들지 못하게 하고, 미체결 한 종목이 다른 위험축소 주문을 장시간 막거나 중복 주문을 만드는 경로를 차단한다.

## 원인과 수정

- `compute_feature_matrix()`가 선택 피처를 포함한 뒤 전체 `dropna()`를 수행해, `^VIX9D`가 1일만 반환된 8/28 학습표가 `1/100일`이 됐다.
- HMM 데이터 부족 경로가 직전 blend 대신 규칙 기반 Goldilocks 100%를 목표로 사용해 23.2% drift와 대규모 risk-on 리밸런싱을 만들었다.
- 선택 피처는 유효값 100일·필수행 대비 80% coverage·최신값 존재를 모두 만족할 때만 채택한다. 필수 학습표는 예상행 대비 70% 미만이면 불량으로 판정한다.
- 불량 회차에는 직전 정상 blend·자산군 목표·유효 변동성·VIX를 동결한다. 단, 가격 기반 규칙이 Crisis이면 위험축소 목표만 예외로 통과한다.
- 기존 `state 변화 N/5`는 재학습 후 숫자 state ID끼리 비교해 ID 순열도 변화로 셌다. 이제 Hungarian anchor로 매칭된 군집의 의미 라벨을 비교하고 유지 수·평균/최대 거리도 함께 기록한다.
- 주문은 종목당 최대 180초, 30초마다 최대 4회 재가격한다. 취소 성공 후 `pending_qty`만 재주문하고 취소 실패 시 신규 주문을 금지한다.
- timeout 매도는 잔고를 다시 조회해 부분체결 수량을 확정하고, 남은 매도는 `failed_sells`에 5영업일 저장해 다음 모니터에서 쿨다운보다 우선 재시도한다.
- 포트폴리오 최초 잔고에서 매도가능수량을 캐시해 종목마다 잔고 API를 호출하지 않는다. `EGW00215`는 2초→4초 backoff를 적용하고 주문 간격은 0.25초→1초로 늘렸다.
- FRED 일부 series 실패는 누락 키만 24시간 이내 캐시로 보충한다. 짧은 10일 벤치마크 조회의 `SPY 9/30일` 거짓 경고도 제거했다.
- 포트폴리오 변동성 계산값이 0일 때는 `0.00%`라고 표시하지 않고 실제 사용되는 SPY EWMA 변동성을 명시한다.
