# USD 미결제 매수·매도 동시 발생 시 총자산 이중계산 수정

> **요약**: ① 2026-08-28 해외 리밸런싱 뒤 총자산이 229,509,216원에서 250,603,147원으로 뛴 현상을 실계좌 raw 잔고와 주문 로그로 진단했다. ② KIS 응답은 미결제 매도 $16,045.79와 매수 $15,289.49를 함께 반환하고 당일 매수 종목도 보유자산에 포함했는데, 기존 코드는 매도액만 현금에 더해 매수액 약 21,085,736원을 이중계산했고 가짜 입금 21,093,931원과 거의 정확히 일치했다. ③ USD NAV 현금을 `출금가능 예수금 + 미결제 매도 - 미결제 매수`로 계산하도록 수정하고 매도만·매수만·동시매매·필드 누락·실제 사례 회귀 테스트를 추가해 채택했다.

## 증상과 원인

08-28 03:01 해외 리밸런싱 전 성과 기준 총자산은 229,509,216원이었다. 같은 실행에서 USD 자산을
$16,045.79 매도하고 $15,289.49 매수했다. 10:00 국내 실행의 KIS 체결기준현재잔고에는 다음 값이
동시에 들어왔다.

- `frcr_drwg_psbl_amt_1`: $586.94
- `frcr_sll_amt_smtl`: $16,045.79
- `frcr_buy_amt_smtl`: $15,289.49
- 당일 매수한 SPY·QQQ·DBC·VEA·VTV·AVUV: 이미 보유종목 평가액에 포함

기존식은 `586.94 + 16,045.79`를 현금으로 잡았다. 새로 산 주식 $15,289.49가 이미 평가액에 있으므로
그 매수액이 현금에도 남은 것처럼 중복됐다. 당시 환율 1,379.1원을 곱한 과대계상액은 21,085,736원이며,
입출금 이상 감지가 자동 기록한 가짜 입금 21,093,931원과 차이가 8,195원뿐이다.

## 수정

`trading/executor.py`에 순수 함수 `_compute_usd_nav_cash`를 추가했다.

```text
USD NAV 현금 = withdrawable_amount + unsettled_sell - unsettled_buy
```

- 매도만 있으면 기존 07-07 수정과 동일하게 gross 매도액 전부를 반영한다.
- 매수·매도가 함께 있으면 순매매액만 반영한다.
- 매수만 있으면 이미 stocks에 들어온 매수 평가액의 반대편 결제 의무를 현금에서 차감한다.
- raw 필드가 없으면 출금가능 예수금만 사용한다.
- 주문가능금액 API 실패 폴백은 NAV용 순매매 현금과 분리해 원래 출금가능 예수금만 사용한다.

## 검증

`python scripts/test_usd_pending_cash.py`

- 매도만: 기준현금 $100 + 매도 $1,000 = $1,100
- 동시매매: 기준현금 $100 + 매도 $1,000 - 매수 $900 = $200
- 매수만: 기준현금 $100 - 매수 $250 = -$150
- 필드 누락: 기준현금 $100 유지
- 08-28 실사례: $586.94 + $16,045.79 - $15,289.49 = $1,343.24

기존 총자산 250,603,147원에서 이중계상된 매수액 21,085,736원을 빼면 약 229,517,411원으로,
리밸런싱 직전 229,509,216원과 8,195원 차이여서 원인이 숫자로 재현된다.
